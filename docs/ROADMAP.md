# AstraOS Roadmap

## v0.4

- Configuration commands
- Clap command parser
- Typed configuration errors
- Structured tracing

## v0.5

- Workspace registry
- Config editing commands
- Shell completions
- JSON diagnostics

## v0.6

- Interactive terminal dashboard
- Live system metrics
- Project status

- Provider-neutral Project Context Engine with deterministic text, JSON, and
  semantic-tree output

## v0.9

- Read-only Project Action Engine foundation with typed Cargo build/check/test
  discovery

- Strict action policy and deterministic dry-run planning

## v0.11

- State-bound controlled execution of the approved Cargo workspace check

## v0.12

- Evidence-backed, versioned Knowledge Foundation
- File-backed verification claims with state-aware validity
- Read-only `astra knowledge` queries

## v0.13

- Deterministic Project Intelligence Foundation
- Read-only `astra project understand` reports
- Evidence-backed runtime relationship graph and grounded insights

## Future

- AI orchestration consuming structured project context
- Cybersecurity workflows
- Stable installer and release channel
